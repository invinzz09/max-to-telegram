# max-to-telegram — мост MAX ↔ Telegram для Claude Code

Навык (skill) для [Claude Code](https://claude.com/claude-code): разворачивает, чинит и обновляет
двусторонний мост между мессенджером **MAX** (web.max.ru) и вашим **Telegram-ботом**.
Читаете и отвечаете в Telegram, а аккаунт MAX живёт в веб-версии на отдельной виртуальной машине —
MAX не видит ни ваш VPN, ни ваш телефон.

## Что умеет мост

**Из MAX в Telegram** (в личку с вашим ботом):
- текст целиком, фото, видео, файлы;
- голосовые — голосовым + **расшифровка текстом** (Whisper локально в ВМ, звук никуда не уходит);
- пересланные сообщения («↪️ Переслано от …») и ответы с цитатой;
- реакции собеседника на ваши сообщения;
- подпись отправителя — как он записан **у вас в контактах Telegram** (по номеру телефона), иначе как в MAX.

**Каждая переписка — своя тема** в чате с ботом (вкладки наверху, как отдельные чаты):
всё от человека приходит в его тему, а что вы пишете в теме — уходит ему.

**Из Telegram в MAX:**
- текст с эмодзи, фото, видео, файлы до 20 МБ — просто пишете в теме человека
  (или «Ответить» на пересланном, или «@Имя» первой строкой);
- написать первым — кнопка «📇 Контакты» (свежие переписки сверху) или «✍️ Написать» (поиск по имени,
  понимает «Настя» = «Анастасия»);
- отметка на вашем сообщении: ✍ — отправляется, 👌 — ушло; при ошибке — сообщение с причиной;
- **только в личные чаты**; адресат сверяется по внутреннему номеру чата MAX, а для файлов —
  ещё и по самой команде отправки до того, как она уйдёт на сервер. В группы не отправляется ничего.

## Как устроено

```
[web.max.ru в Edge]  ← отдельная Windows-ВМ (VirtualBox, сеть «мост», без VPN)
     │ Chrome DevTools Protocol
  maxfwd.py + hook_cdp.js  (читает кадры веб-сокета MAX, отправляет в MAX)
     │ SOCKS5-прокси на основном ПК (только к Telegram)
  Telegram Bot API  ↔  ваш бот  ↔  вы
```

Только стандартная библиотека Python, никаких сторонних пакетов. Для расшифровки голосовых —
готовые сборки whisper.cpp и ffmpeg.

## Как поставить

**Проще всего — поручить своему Claude.** Открыть Claude Code и вставить:

> Установи навык из https://github.com/invinzz09/max-to-telegram : скачай архив main-ветки, распакуй и скопируй папку `max-to-telegram` в `%USERPROFILE%\.claude\skills\` (создай папку, если нет). Потом покажи, что получилось.

После этого перезапустить Claude Code — навык появится в списке по `/`. Дальше достаточно сказать
«настрой пересылку MAX в телеграм» — Claude проведёт по шагам.

**Вручную:** Code → Download ZIP, папку `max-to-telegram` скопировать в
`C:\Users\<имя>\.claude\skills\` (должно получиться `…\skills\max-to-telegram\SKILL.md`), перезапустить Claude Code.

## Что понадобится

- Windows-ПК, на котором можно держать включённой виртуальную машину (VirtualBox, 4 ГБ ОЗУ, 2 ядра, ~70 ГБ диска;
  в BIOS включена аппаратная виртуализация).
- Telegram-бот (создаётся у @BotFather за минуту) и ваш chat_id. У @BotFather → «Open» → ваш бот →
  Bot Settings включить **Threaded Mode** (темы) и «Disallow users to create new threads».
- Путь в Telegram с этого ПК: если Telegram у вас заблокирован — VPN на основном ПК
  (через него пойдёт только трафик бота; MAX ходит напрямую из ВМ).
- Аккаунт MAX и телефон с MAX — один раз войти по QR-коду в веб-версии внутри ВМ.

## Безопасность

- В коде нет секретов: токен бота, chat_id и пароль прокси — только в вашем `config.ini`.
- Команды бот принимает только от вашего chat_id, каждую — не больше одного раза.
- Голосовые расшифровываются на вашей ВМ, никуда не отправляются.
- Подписи из Telegram берутся из **вашей** выгрузки контактов (Telegram Desktop → Экспорт данных),
  из неё сохраняются только номер и имя, файл остаётся у вас.

## Если сломалось

Мост работает с веб-версией MAX и может сломаться при её редизайне. В навыке описано, что и как
чинить, — достаточно сказать своему Claude «почини пересыльщик MAX».
